ArcGIS OAuth Compatibility Test

This isolated page tests whether an ArcGIS Online organisation will start a normal OAuth sign-in flow for an externally registered application. Nothing entered here is stored in the repository.

Safe-test boundary: this page only opens the standard ArcGIS OAuth authorisation endpoint. It does not request administrator approval, access private layers, exchange an authorisation code for a token, or contact an administrator.
Stop immediately if ArcGIS shows wording such as Request approval, Request access, Contact your administrator, or says the application must be approved. Do not click any approval/access-request control.

If you instead reach a normal app consent/permissions page, stop there as well and review it before selecting Allow/Approve.
